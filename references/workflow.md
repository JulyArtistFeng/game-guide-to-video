# 攻略文档转视频 · 详细工作流

开始执行攻略转视频任务时完整读取。

---

## 第一步：读取攻略文档

### 飞书文档
```bash
lark-cli docs +fetch --doc "DOC_ID" --scope range --start-block-id 0 --end-block-id -1
```
提取：h1/h2 章节结构、每章正文、表格数据、图片 caption。

### 本地文件
- Word：用 word skill 读取
- Markdown/纯文本：直接 Read
- PDF：用 doubao-pdf 读取

### 输出
- 章节清单：[{章节号, 标题, 字数, 核心要点, 关键数据}]
- 全文内容用于后续拆分

---

## 第二步：按时长拆分内容

### 时长换算表

| 视频时长 | 旁白字数 | 适合内容 |
|---|---|---|
| 1 分钟 | 200-220 字 | 单个小技巧/道具介绍 |
| 2 分钟 | 400-450 字 | 一个机制/系统入门 |
| 3 分钟 | 600-670 字 | 一个完整章节/Boss打法 |
| 5 分钟 | 1000-1100 字 | 大型系统详解 |

### 拆分原则
1. 先按文档自然章节拆分
2. 单章超过 700 字 → 拆成 2 集
3. 单章少于 300 字 → 与相邻章节合并
4. 第一集：总览+入门（"这个游戏怎么玩"）
5. 最后一集：总结+进阶提示+资源获取引导

### 合集规划表模板
| 集数 | 标题 | 对应文档章节 | 旁白字数 | 核心画面关键词 |
|---|---|---|---|---|
| EP01 | 开局第一天怎么活 | 一、开局生存 | 500 | 草地、捡资源、点火 |
| EP02 | 建家选址与布局 | 三、建家 | 550 | 基地布局、猪王桦树林 |

---

## 第三步：生成旁白脚本

### 口语化改写规则
- 书面语 → 口语："玩家需要在第一夜前建立光源" → "第一天晚上之前你必须搞到火把"
- 被动 → 主动："格罗姆会被雕像吸引" → "月圆之夜格罗姆会自己飞过来"
- 数据说人话："生命值+40，饱食度+37.5" → "一口回40血，还能填肚子"
- 步骤用连接词："先…然后…接着…最后…"

### 每集结构模板
```
【开头钩子 5-10秒 / 30-50字】
"今天教你XX""很多新手都死在XX""其实XX很简单"

【正文 80% / 350-500字】
按逻辑顺序讲解，穿插"注意""划重点""很多人不知道"

【结尾 10-15秒 / 50-80字】
总结要点 + "下期讲XX" + "完整版攻略点赞关注私信领取"
```

### 旁白脚本输出格式
纯文本，每句一行，方便后续生成音频和对齐字幕：
```
今天教你饥荒联机版开局第一天怎么活。
出生先捡草和树枝，这俩是最基础的材料。
沿着路走，找猪王桦树林，那里适合建家。
...
完整版攻略点赞关注，私信我领取。
```

## 第四步：生成旁白音频

### text_to_audio_plus 参数
```
prompt: "25岁活力男声，游戏攻略解说风格，语速稍快，自然有热情，说：{旁白文本}"
duration: 按字数/200 计算（秒），如500字≈150秒
```

### 声音选择建议
- 生存/建造类游戏：沉稳男声，有安全感
- 动作/竞技类游戏：年轻活力男声，语速快
- 可爱/休闲类游戏：清亮女声，亲切
- 恐怖类游戏：低沉男声，氛围感

### 注意
- 旁白文本不要含表情符号和舞台指示
- 专有名词（游戏名、道具名）发音不确定时，用拼音或常见读法
- 生成后检查时长，与目标时长偏差超过 15% 则调整文本重生成

---

## 第五步：准备游戏画面

### 画面搜索关键词技巧
- 按集主题搜索："饥荒联机版 月圆之夜""饥荒 洞穴入口"
- 加"实机""游戏画面"过滤立绘和宣传图
- 英文游戏名搜索可能结果更好："Don't Starve Together full moon"

### 静态图转动效（image_to_video）
- 对搜索到的游戏截图，用 image_to_video 生成 3-5 秒动态片段
- prompt："缓慢向右平移，轻微推拉，保持游戏画面不变"
- 避免生成改变游戏画面内容的动效（不要让角色动起来）

### 画面数量
- 2-3 分钟视频需要 5-8 个画面片段
- 每个片段 3-8 秒
- 画面切换频率与旁白节奏匹配，不要 1 秒一切也不要 30 秒不换

---

## 第六步：合成视频

### byted-mediakit-editing 合成顺序
1. 导入所有画面片段，按旁白顺序排列
2. 导入旁白音频，对齐画面
3. 添加字幕（逐句对齐旁白）
4. 添加 BGM（音量 -15dB）
5. 添加片头（3-5秒）
6. 添加片尾话术（5-8秒）
7. 转场：画面之间淡入淡出 0.5 秒
8. 导出 MP4 1080p

### 片尾话术模板
- "完整版攻略内容请点赞并添加关注，私信我领取"
- "觉得有用就点个赞吧，关注我看更多游戏攻略"
- "下期讲XX，别忘了关注哦"

### 批量输出
- 每集独立文件：`{游戏名}_EP{集数}_{标题}.mp4`
- 全部完成后输出合集清单
