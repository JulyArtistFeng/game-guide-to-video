# 旁白脚本模板与话术库

写旁白脚本时读取。本文档提供各类型攻略的旁白模板、开头钩子库和结尾话术库。

---

## 开头钩子库（前 5-10 秒）

### 新手向
- "今天教你{游戏名}开局第一天怎么活"
- "90%的新手都死在{某件事}，其实只要这样做"
- "{游戏名}入门很难？看完这集你就会了"
- "别再瞎玩了，{游戏名}正确开局是这样的"

### 机制/技巧向
- "很多人不知道，{道具/机制}其实可以这样用"
- "{机制}的隐藏用法，老玩家都不一定知道"
- "学会这招，{游戏名}难度直接减半"
- "你还在{错误做法}？正确做法是这样的"

### Boss/战斗向
- "{Boss名}打不过？看完这集闭眼过"
- "全网最详细的{Boss名}打法，没有之一"
- "{Boss名}的致命弱点是这个，90%的人不知道"
- "零装备打{Boss名}，其实很简单"

### 建家/资源向
- "建家选址选错，后期全废，正确位置是这里"
- "{资源}不够用？教你无限获取的方法"
- "完美基地布局，照着建就行"
- "前期必做的{数量}件事，少一件都不行"

## 结尾话术库（最后 10-15 秒）

### 标准引导
- "完整版攻略内容请点赞并添加关注，私信我领取"
- "觉得有用就点个赞，关注我看更多{游戏名}攻略"
- "这期就到这里，下期讲{下期主题}，别忘了关注"

### 互动引导
- "你还有什么想知道的？评论区告诉我"
- "你觉得{某道具/机制}怎么样？评论区聊聊"
- "关注我，下期更精彩"

### 合集引导
- "这是{游戏名}攻略合集第{集数}集，往期视频在主页"
- "关注我，追更{游戏名}攻略合集"
- "合集持续更新中，点赞关注不迷路"

## 各类型攻略旁白模板

### 模板一：新手入门（2-3分钟）
```
【钩子】今天教你{游戏名}开局第一天怎么活。
【背景】很多新手刚进游戏不知道干嘛，到处乱跑，晚上就死了。
【步骤1】出生先捡{基础资源}，这俩是最基础的材料，见一个捡一个。
【步骤2】然后沿着路走，找{适合建家的地形}，那里有{优势}。
【步骤3】第一天晚上之前必须搞到{光源/避难所}，不然{后果}。
【注意】划重点：{常见错误}，很多新手都栽在这。
【总结】第一天记住这三点：{要点1}{要点2}{要点3}。
【结尾】下期讲{下期主题}。完整版攻略点赞关注，私信我领取。
```

### 模板二：机制详解（2-3分钟）
```
【钩子】很多人不知道，{机制名}其实可以这样用。
【是什么】{机制名}就是{一句话解释}，在{条件}下触发。
【怎么用】具体操作是这样：先{步骤1}，然后{步骤2}，最后{步骤3}。
【有什么用】学会这个，你可以{好处1}，还可以{好处2}。
【注意】注意{限制条件/常见错误}，不然会{后果}。
【进阶】进阶玩法：{高阶技巧}，老玩家都这么用。
【结尾】学会了吗？点赞关注，下期讲{下期主题}。
```

### 模板三：Boss打法（2-3分钟）
```
【钩子】{Boss名}打不过？看完这集闭眼过。
【Boss介绍】{Boss名}是{位置/条件}出现的Boss，血量{数值}，攻击{数值}。
【准备】打之前准备好{装备1}{装备2}{装备3}，食物带{回复品}。
【阶段1】第一阶段：{攻击模式}，应对方法是{打法}。
【阶段2】第二阶段：{攻击模式}，应对方法是{打法}。
【关键】划重点：{致命弱点/关键时机}，抓住这个机会输出。
【掉落】打死掉{掉落物}，可以用来{用途}。
【结尾】还想看哪个Boss？评论区告诉我。完整版攻略点赞关注私信领取。
```

### 模板四：建家/布局（2-3分钟）
```
【钩子】建家选址选错，后期全废，正确位置是这里。
【选址】推荐建在{地形}，因为{优势1}{优势2}。
【布局】基地布局照着来：{建筑1}放{位置}，{建筑2}放{位置}。
【优先级】前期先建{必建建筑}，中期补{进阶建筑}。
【注意】别把{建筑}放在{错误位置}，不然{后果}。
【进阶】后期可以加{进阶设施}，大幅提升效率。
【结尾】你的基地建在哪了？评论区晒晒。关注我下期讲{下期主题}。
```

| 精神值-5 | 掉5点san |
| 位于XX地形 | 在{地形}能找到 |
| 推荐组合 | 最好搭着用 |
| 注意避免 | 别 / 千万别 |

| 然而 | 但是 / 不过 |
