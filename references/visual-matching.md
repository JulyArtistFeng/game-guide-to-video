# 游戏画面匹配指南

准备视频画面素材时读取。本文档提供旁白内容与游戏画面的匹配关键词、搜索技巧和静态图转动效参数。

---

## 旁白内容 → 画面关键词匹配表

### 生存建造类（以饥荒为例）

| 旁白内容 | 搜索关键词 | 画面类型 |
|---|---|---|
| 开局/出生 | "{游戏名} 开局 草地" | 角色出生在草地 |
| 捡资源 | "{游戏名} 采集 草 树枝" | 角色捡拾资源 |
| 建家/基地 | "{游戏名} 基地 布局" | 完整基地俯瞰 |
| 烹饪/做饭 | "{游戏名} 烹饪锅 食谱" | 烹饪锅界面/做饭 |
| 种植/农场 | "{游戏名} 农田 作物" | 农田/巨型作物 |
| 战斗/打怪 | "{游戏名} 战斗 怪物" | 战斗场景 |
| 洞穴/地下 | "{游戏名} 洞穴 入口" | 洞穴入口/地下 |
| Boss战 | "{游戏名} {Boss名} 打法" | Boss战斗画面 |
| 月圆/特殊事件 | "{游戏名} 月圆之夜" | 月圆场景 |
| 冬季/季节 | "{游戏名} 冬天 雪地" | 冬季场景 |
| 科技/制作 | "{游戏名} 科技栏 制作" | 制作界面 |

### 通用匹配原则

1. **讲到什么就搜什么**：旁白提到"烹饪锅"就搜烹饪锅画面
2. **动作匹配**：讲到"打怪"用战斗画面，讲到"建家"用基地画面
3. **情绪匹配**：紧张时刻用战斗/危险画面，轻松时刻用日常画面
4. **数据界面**：讲到配方/数值时，用游戏内界面截图（烹饪锅界面、科技栏）

## 画面搜索技巧

### 关键词组合
- 基础："{游戏名} {主题}"
- 加限定："{游戏名} {主题} 实机""{游戏名} {主题} 游戏画面"
- 英文："{英文名} {topic} gameplay""{英文名} {topic} screenshot"
- 版本："{游戏名} 联机版"（区分单机版）

### 筛选标准
- ✅ 真实游戏截图/实机画面
- ✅ 画面主体与旁白内容对应
- ✅ 分辨率 ≥1280×720（纯游戏画面低分辨率也可接受）
- ❌ 立绘/宣传图/封面图
- ❌ 带大面积水印/营销卡片
- ❌ 其他游戏的画面
- ❌ 攻略文字截图（含密集文字的图片不适合做视频画面）

## 静态图转动效（image_to_video）

### 适用场景
- 搜索到的是静态截图，需要变成动态视频片段
- 游戏画面本身没有动效，需要增加视觉动感

### 推荐动效参数
```
prompt: "镜头缓慢向右平移，同时轻微向前推拉，保持游戏画面内容不变，不添加任何新元素"
duration: "4"
ratio: "16:9"
```

### 动效类型选择
| 画面类型 | 推荐动效 |
|---|---|
| 大场景/基地俯瞰 | 缓慢推拉（zoom in/out） |
| 角色/建筑特写 | 缓慢平移（pan left/right） |
| 战斗画面 | 轻微晃动（增加紧张感） |
| UI界面 | 静止或极慢推拉 |

### 注意事项
- 不要让 AI 改变游戏画面内容（不要生成新角色、新建筑）
- 动效要慢，3-5 秒内变化不超过画面 20%
- 如果 image_to_video 效果不好（画面变形），直接用静态图+ Ken Burns 效果（在剪辑时做缩放动画）

## 画面片段时长与切换

### 单片段时长
- 场景展示：5-8 秒
- 动作/战斗：3-5 秒
- UI界面：4-6 秒
- 特写：3-4 秒

### 切换频率
- 2-3 分钟视频：5-8 次画面切换
- 平均每 20-30 秒换一次画面
- 旁白讲到新主题时必须换画面
- 不要 1 秒一切（太晕），也不要 30 秒不换（太闷）

### 转场
- 默认：淡入淡出 0.5 秒
- 快节奏内容：硬切（无转场）
- 主题转换：缩放转场或闪白
